Define what progression and mastery look like for each skill. Levels should be based on milestone outcomes and demonstrated capabilities, not time spent.

## Key Questions
- Is there a universal mastery scale or is it unique per skill?
- What defines each level? (capabilities, outcomes, observable behaviors?)
- How granular should levels be? (3 tiers? 5? 10?)
- How do we handle skills where mastery is subjective vs. clearly measurable?
- Can we define "level templates" for common skill types?

## Checklist
- [ ] Research mastery/competency models (Dreyfus, Bloom's, belt systems, etc.)
- [ ] Design a flexible mastery schema that supports per-skill customization
- [ ] Define mastery levels for pilot skills from Lane 1
- [ ] Build UI to display mastery levels on skill nodes
- [ ] Create a framework for contributors to define mastery scales for new skills
