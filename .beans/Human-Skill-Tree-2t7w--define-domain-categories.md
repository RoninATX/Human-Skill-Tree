Research and define the top-level domain categories that organize all human skills. These are the broadest containers in the tree.

## Context
The current tree is flat — just nodes and edges with no domain concept. We need to decide on the top-level categories that feel intuitive, comprehensive, and not overly academic.

## Considerations
- Should cover the full breadth of human capability
- Categories should be roughly balanced in scope (no catch-all buckets)
- Should feel natural to a non-expert browsing the tree
- Need to decide if domains can overlap or if placement is strict
